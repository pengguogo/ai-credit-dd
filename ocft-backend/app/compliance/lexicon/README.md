# 合规词库

每个 `.txt` 是一个类别，一行一个词或短语，`#` 开头为注释，匹配不区分大小写。改词库不需要改代码，重启后端生效。

| 文件 | 类别 | 处理 |
|------|------|------|
| `politics.txt` | 政治敏感 | 拒绝 |
| `porn.txt` | 色情低俗 | 拒绝 |
| `abuse.txt` | 辱骂歧视 | 拒绝 |
| `crime.txt` | 违法犯罪诱导（洗钱、诈骗、套现等） | 拒绝 |
| `privacy.txt` | 窃取他人隐私 | 拒绝 |

新增词条后，在 `tests/compliance_cases.py` 补一条正例，运行 `pytest tests/test_compliance.py` 确认拦截率与误拦率。

局限：关键词匹配无法理解语义，存在漏拦（变体、谐音）和误拦（正常语境中出现敏感词）。请以样例集持续补充。
