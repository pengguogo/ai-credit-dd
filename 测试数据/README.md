## 归档约定

- 路径优先使用 `评测/YYYY-MM-DD/<commit-or-batch>/`，同一批次内保存开始记录、配置哈希、原始结果、摘要、逐题比较和必要证据。
- 官方公开集、自然语言问询、团队衍生集和现场官方非公开集必须明确区分。
- 运行时输入只含业务字段；参考答案、`expected` 和事实标签只在离线评分层读取。
- 失败与待确认状态原样记录，不补模板结论，不回填旧运行结果。
- 截图、日志和导出不得包含未脱敏的个人敏感信息、密码、API Key 或真实连接串。
- 临时输出放 `ocft-backend/eval/output/`，默认不提交；正式输出只保存官方要求的文件和对应状态旁表。
