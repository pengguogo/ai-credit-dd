# 公开评测通用缺陷修复与复测

日期：2026-10-24。用户已授权修改公共编排、工具、场景配置及契约；本轮是缺陷修复，不执行尚未确认的企业尽调草稿 spec。

## 分析结论

分析了 `dd04-baseline`、`dd04-env-retry` 和 `dd04-token-1m` 三轮归档。首轮申请为 4 成功、3 待确认、3 Token 超限；同环境复跑为 6 成功、2 待确认、2 Token 超限；增大预算后为 5 成功、3 待确认、2 轮次耗尽。三轮工具额度均为 0，因此不能把放宽预算解释为业务修复。

最新两笔轮次耗尽轨迹都在取得计算或报告后继续执行 SQL。所有计算工具自行读取数据库，但提示词没有说明可以同轮批量检查，也没有说明报告后停止复算。该问题用通用流程指引处理，不缓存样本、不屏蔽未见题、不按编号设置分支。

## 修改点、影响范围与验证方式

|修改点|影响范围|验证方式|
|---|---|---|
|`已执行完毕` 加入 `closed_statuses`|所有企业司法分桶及依赖司法得分的评级；原金额、历史已结司法计分仍保留|三个不同金额的合成样本，未结金额仅包含真正未结案件|
|保留 `eventContent`、`eventSource`|舆情工具结果、证据、模型输入；继续沿用现有脱敏|两段不同正文的透传测试，原事实不改写|
|模型 `length` 截断判为 `llm_output_incomplete`|所有场景的在线、异步和评测入口|有/无工具响应及已有证据三类路径；禁止发布半份答案或执行截断工具调用|
|模型响应后验收 Token/时限|所有场景的终态，补齐原来只在下一次调用前检查的漏洞|小于、等于、大于预算及跨轮累计、超时返回测试；失败保留真实 usage 和已取得证据|
|审计保存 `finishReason` 和验收失败码|现有 JSON 响应预览及阶段事件，无表结构变更|审计字段测试及全量回归|
|定位后复用编号、同轮批量检查、报告后直接成文|企业尽调提示词，SQL 仍可补查工具未提供的原始事实|指引回归检查及同输入真实复测；提示词不是模型服从性的保证|
|完整报告控制篇幅、问询只回答所问要点|企业尽调提示词，五部分结构与关键依据仍保留|首轮实际发现两条 `length` 后补篇幅指引；第二批 `concise-retry/` 同输入重跑，不覆盖第一批|
|区分同比/累计/复合增长、禁止由汇总逾期推断逐年逾期、禁止无营业成本推断毛利率|企业尽调解释指引|真实问询复测，全文事实正确性仍需独立评分|

表结构未变：`case_status → caseStatus/案件分桶`，`event_content/event_source → eventContent/eventSource`。供应方 `finish_reason → responsePreview.finishReason/运行终态`。契约在代码前更新。

## 不做数据硬编码

- 不修改事实 CSV、参考答案、`expected`、额度公式、评分卡权重或评级阈值。
- 不读取外部汇总评级作为本系统评分答案，不构造题号到结论映射。
- 模型仍锁定 `deepseek-v4.1-flash`，仅经 `app/llm.py`；不修改 `.env`。
- 本机当前配置为 6 轮、60 秒、累计 1,048,576 Token、单次输出 2,048 Token。保持与 `dd04-token-1m` 相同预算比较。
- Token 在供应方响应后才能获得，因此严格控制的是结果验收，不能保证实际消耗绝不超过预算。达到预算时可验收完整答案，但不再进行下一次调用。
- 执行完毕的通用状态语义由 YAML 配置控制，不针对任何企业、案件号或具体金额设置例外。

## 仍需业务确认

1. 当前额度公式先取多口径上限，再扣存量贷款和对外担保。现有输入扣减后为非正数，输出 0 符合当前代码；是否测算总授信或新增额度、扣减次序与适用范围，需要业务决定，不能为贴合参考额度调参数。
2. 当前评分卡与外部/参考风险档位存在差异；本轮司法分桶修正可能自然改变评分，但不保证匹配参考。本轮不人为修改阈值。
3. 首轮已核对出参考数据冲突：涉诉汇总与明细不符、应收与营收增速描述不符。保留原始参考，不改标签提分。
4. `succeeded` 仅表示通过执行终态验收，不是全文事实正确率；待确认不是失败，但也不是已确认业务结论。不用中间工具报告回填失败或自动确认高风险结果。
5. 非公开题未运行；正式六列完整提交和全文独立评分未验收。
6. 最终问询仍发现模型解释问题：把财务费用直接等同利息覆盖、把某条未命中的数值 0.0939 描述为低于 0.02，以及担保期限混用现实日期与申请时点。工具事实与数字未改，不能因此声称解释完全正确。这些需要继续做通用数值/时间口径校验，不能靠替换某题答案解决。
