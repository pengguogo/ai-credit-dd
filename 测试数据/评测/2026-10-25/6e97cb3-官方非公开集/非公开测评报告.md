## 3. 首轮发现的缺陷与修复

首轮（`6e97cb3` 原样，目录 [`runs/`](runs/)、[`official-export/`](official-export/)）：15 succeeded / 5 needs_confirmation，但 **LA013、LA028、LA029、LA030 四笔未生成评级与额度**。

| 项 | 内容 |
|---|---|
| 现象 | 财报解析角色 `execution_failed`：`TypeError: float() argument must be a string or a real number, not 'complex'`；下游反欺诈、评级授信、报告角色连带未运行，约 9 s 即结束 |
| 根因 | `app/tools/dd_calc.py::_cagr` 只排除了起点 ≤ 0，四家企业 2023 年净利润为负，`(负数/正数) ** (1/2)` 在 Python 中返回复数 |
| 修复 | 末值 < 0 时 CAGR 返回 `None`（增长率无定义），通用规则，不针对样本；新增回归测试 `test_cagr_undefined_when_end_value_negative` |
| 验证 | 后端 `570 passed / 1 skipped`；红线扫描 0 ERROR / 3 既有 WARN；重跑后四笔均产出高风险 / 0 |
| 暴露原因 | 公开集 10 家末年净利润均为正，未覆盖该分支；属于非公开集验证泛化能力的真实收益 |
