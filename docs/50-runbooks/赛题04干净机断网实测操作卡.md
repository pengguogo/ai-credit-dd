- [ ] DeepSeek Key 在控制台设好消费上限（≤1000 元）

## 步骤（干净 Windows，真断网装依赖）

1. 将 `*_赛题04_可运行系统包.zip` 拷到干净机空目录，解压。**解压后根目录应直接看到** `README.md`、`start.bat`、`ocft-backend/`、`vendor/`，不要多套一层。
2. **断开或阻断**包管理器外网（或对 pip 设死代理），确认不会 `pip install` 联网拉包。
3. 双击 `start.bat`（即 `start.ps1 -Offline`）。等待内置 Python 解压 + wheel 离线安装 + 服务起来（约 2–4 分钟）。
4. 浏览器打开 http://127.0.0.1:8000 ；另开终端：
   ```bat
   curl http://127.0.0.1:8000/api/health/ready
   ```
   期望：HTTP 200，`modelLock.model == "deepseek-v4.1-flash"`，database ok。
5. 页面点开首页、报告相关入口；未知路径应 404。
6. 按根目录 README「批量测评」示例跑至少 1 笔（如 LA001），场景 ID 必须是 `enterprise_dd`（不是 `enterprise_due_diligence`）：
   ```bat
   cd ocft-backend
   .venv\Scripts\python.exe -m eval.prepare ...
   .venv\Scripts\python.exe -m eval.run ...
   .venv\Scripts\python.exe -m eval.export ...
   .venv\Scripts\python.exe -m eval.validate ...
   ```
7. 确认导出六列、`utf-8-sig`、Excel 打开无乱码。
8. 在 README / `manifest.yaml` 中确认已写 `network_required: true`（模型 API + 云库；依赖本身离线）。
