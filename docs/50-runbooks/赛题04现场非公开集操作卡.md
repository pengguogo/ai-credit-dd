## 1. 拿到样本后先看什么

1. 是否有 **9 张业务表** + 可选 `schema_relationships.csv`（表头与官方公开包一致）。
2. 是否另有 **贷款申请表**（至少含 `application_id,enterprise_id`）；问询表可选。
3. **没有** `公开测试集答案.csv` / `reference_answer` 时属正常；不要向 Agent 注入任何参考答案。
4. 若现场是 **pdf**：本仓库批量 CLI **不支持 pdf**。预案：人工（或评委允许的工具）转成与官方同结构的 csv/xlsx，再走本卡；并在 README 如实声明。

## 3. 评测流水线（一条龙）

```bash
cd ocft-backend

# 1) 只生成无标签输入
.venv/bin/python -m eval.dd04 prepare \
  --input <现场loan_application.csv> \
  --kind applications --scenario-id enterprise_dd \
  --output eval/output/field-nonpublic/applications.jsonl

# 可选：问询
.venv/bin/python -m eval.dd04 prepare \
  --input <现场question.csv> \
  --kind questions --scenario-id enterprise_dd \
  --output eval/output/field-nonpublic/questions.jsonl

# 2) 统一入口跑题（会调模型、产生费用）
.venv/bin/python -m eval.run \
  --input eval/output/field-nonpublic/applications.jsonl \
  --output-dir eval/output/field-nonpublic/runs --fresh

# 3) 官方六列 + status
.venv/bin/python -m eval.dd04 export \
  --applications <现场loan_application.csv> \
  --runs eval/output/field-nonpublic/runs/results.jsonl \
  --output ../系统输出/<队名>_赛题04_非公开测评集结果.csv

# 4) 格式校验（不评业务对错）
.venv/bin/python -m eval.dd04 validate \
  --applications <现场loan_application.csv> \
  --results ../系统输出/<队名>_赛题04_非公开测评集结果.csv
```

失败 / `needs_confirmation` **如实保留**，不要为通过 validate 填模板结论。
