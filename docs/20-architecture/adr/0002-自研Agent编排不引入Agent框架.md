# 0002 自研 Agent 编排，不引入 Agent 框架

状态：已取代（by 0004）    日期：2026-10-21    提出方：Agent 核心

## 背景

比赛要求 Agent 行为、工具编排、业务逻辑由团队代码实现，禁止低代码平台拼装。LangChain / LangGraph / CrewAI 等框架虽不在禁止之列，但会接管编排核心，削弱"自研"的证明力，执行路径也更难审计。

## 决策

编排层全部自研：`app/agent/engine.py` 有界工具循环、`app/tools/registry.py` 工具注册与参数校验、`app/services/run_service.py` 单事务落库。模型只通过 `app/llm.py` 以 OpenAI 兼容协议直接调用，SDK 仅用于发送 HTTP 请求。

## 后果

- 好处：每一步执行都在自己的代码里，可审计、可解释；评委能直接读懂核心逻辑。
- 代价：状态保存、重试、分支需自己写。
- 重访条件：分支与恢复逻辑复杂到自研难以维护时，再评估图编排框架，并新增 ADR。
