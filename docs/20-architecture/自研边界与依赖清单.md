# 自研边界与依赖清单

> 用途：向评委说明本项目是从零自研的 Agent，并列出所有第三方依赖及其用途。
> 维护规则：新增任何依赖都要在本表登记一行，否则不准合入（见 [评审清单](../30-standards/review-checklist.md)）。
> 最近核对：2026-10-24，依据 `ocft-backend/requirements.txt`、`ocft-backend/requirements-dev.txt`、`ocft-starter/package.json`、当前 ORM / 迁移与运行时 Skill 配置。

## 1. 结论

- 没有使用扣子（Coze）、Dify、FastGPT 等 Agent 平台，也没有使用 CrewAI、AutoGen。
- 编排调度使用 LangGraph（ADR-0004）：只决定 model / tools 的下一跳。模型入口、工具协议、证据链、审计、合规、业务规则仍是本仓库代码。
- 其余第三方依赖是通用基础设施：Web 框架、ORM、校验库、模型 HTTP SDK、前端 UI 库。

## 2. 自研模块

| 模块 | 文件 | 自研内容 |
|------|------|---------|
| Agent 引擎 | `ocft-backend/app/agent/engine.py`、`graph.py` | 终态判定、轮数 / 时限 / token 上限；LangGraph 只调度 model 与 tools 两个节点 |
| 场景注册 | `ocft-backend/app/agent/scenarios.py` | 场景 = Prompt + 工具白名单 + 环节 Skill |
| 运行时 Skill | `ocft-backend/app/agent/skills.py`、`ocft-backend/scenarios/dd04/skills/*.md` | 赛题 04 六个角色 Agent（工商核验、财报解析、舆情扫描、反欺诈、评级授信、报告）的输入契约与成文规则，带版本号；角色调用模型时拼进 system 消息，run 记录 `skillsApplied` |
| 工具协议 | `ocft-backend/app/tools/registry.py` | 工具声明、JSON 参数解析与类型校验、统一 `ToolResult` |
| 业务工具 | `ocft-backend/app/tools/due_diligence.py`、`dd_calc.py`、`credit.py`、`sql_query.py` | 赛题 04 尽调工具与评分卡；`credit.py` 仅作引擎/评测单测夹具；只读 SQL |
| 评测与批量测评 | `ocft-backend/eval/` | 题目加载（jsonl / json / csv / xlsx / 目录）、规则评分、泄漏检查、断点续跑、csv / xlsx 导出 |
| 离线交付 | `pack-offline.ps1`、`start.ps1 -Offline`、`start.bat`（仅 Windows；离线包 `vendor/` 入库） | 下载 wheel、构建前端；离线安装并由后端同源提供页面 |
| 编排服务 | `ocft-backend/app/services/run_service.py` | run 生命周期、单事务落库、确认幂等与版本校验、SSE 事件重建 |
| 合规 | `ocft-backend/app/compliance/checker.py` | 输入输出双端规则：提示注入、标签探测、违规金融承诺 |
| 模型入口 | `ocft-backend/app/llm.py`、`config.py` | 模型锁定、错误类型化、超时、usage 记录 |
| 领域类型 | `ocft-backend/app/domain/` | 状态机常量、证据记录、错误类型 |
| 数据模型 | `ocft-backend/app/models.py`、`migrations.py` | 当前代码管理 29 张 ORM 表，另有 1 张迁移元数据表 `schema_migrations`，合计 30 张；外部云实例可能保留历史表，不以此表述其实时物理表数 |
| 接口契约 | `contracts/agent-api.md` | `/api/agent/*` 全部接口定义 |
| 前端 | `ocft-starter/src/`（hooks、lib、components/chat·run·catalog） | 对话、业务表选企业、实时执行轨迹、证据快照、审计与业务确认；Agent 回复原文导出 PDF/Word（`lib/answer-export.ts`，无第三方导出库） |
| 开发工具 | `.agents/skills/` | 红线扫描脚本、开发流程 Skill |
