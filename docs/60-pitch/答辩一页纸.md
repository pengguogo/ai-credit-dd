# 赛题 04 · 企业智能信贷尽调答辩一页纸

> 架构以当前实现为准；数字只引用带 SHA 的真实归档。流程跑通、格式校验通过均不等于业务满分。

## 一句话

我们做的是**赛题 04 主控 Agent + 六个专业角色的可评测、可审计尽调系统**：结构化工具负责取数和计算，模型负责理解与表述，结论绑定证据，关键事实发布前校验，失败与待确认如实留痕。

## 业务问题与解法

- 企业尽调数据跨工商、财务、舆情、诉讼、担保和贷款记录，人工串联慢且难复盘。
- 大模型能生成流畅报告，但数字、评级、额度和来源若不可验证，会把“看起来合理”误当成业务事实。
- 系统由主控定位对象、拆解任务并调度六角色；确定性计算、证据落库、事实校验和终态门禁共同约束最终输出。

## 当前架构

```text
前端工作台（业务数据 · 对话 · 角色轨迹 · 证据 · 确认 · 报告导出）
        │  POST /api/agent/runs + SSE
        ▼
run_service（执行记录、证据与审计）
        │
输入合规 ──命中风险──▶ blocked（不调模型）
        │
赛题 04 主控 Agent（定位 · 调度 · 追问成文）
        │  run_dd_agents / LangGraph
        ▼
确定性计算（按业务依赖生成工商、财务、舆情、反欺诈、评级结构化结果）
        │
工商核验 / 财报解析 / 舆情扫描 / 反欺诈 / 评级授信（五角色并行解读）
        │
报告角色汇总 ─▶ 事实校验
        │
规则计算与只读查询 ─▶ evidence（来源、主键、快照、哈希、runId）
        │
终态判定（成功 / 待确认 / 待澄清 / 证据不足 / 拦截 / 失败）
        │
输出合规 + PII 掩码 ─▶ 发布答案与只追加审计

模型：deepseek-v4.1-flash；唯一入口：ocft-backend/app/llm.py
```

## 六角色分工

| 角色 | 主要职责 | 输出约束 |
|------|----------|----------|
| 工商核验 | 企业基本信息、经营异常、关联关系、对外担保 | 事实来自业务表与工具证据 |
| 财报解析 | 近三年科目、指标与趋势 | 指标由确定性逻辑计算；缺科目不编造 |
| 舆情扫描 | 涉诉、处罚、负面事件及影响 | 事件保留来源与时间 |
| 反欺诈 | 交叉核验与规则命中 | 规则结果可追溯 |
| 评级授信 | 风险等级、额度与复核信号 | 结论读取结构化计算结果 |
| 报告 | 汇总企业概况、财务、风险、额度与条件 | 发布前校验数字、评级等事实 |

## 工程亮点

1. **结论与表述分离**：规则和计算工具基于当前业务输入实时生成结构化结果，模型不读取评测标签，也不保存题号到答案的映射。
2. **证据链可复盘**：工具证据绑定 runId，包含来源、主键、快照和哈希；页面、HTTP 与批量评测共用同一条业务链路。
3. **发布前事实校验**：报告和追问中的数字、评级等可验证事实与工具结果核对；允许按问题清单重写一次，仍失败则返回结构化错误。
4. **诚实终态**：查不到、缺证据、需澄清、需人工确认或模型失败均显式呈现，不用模板结论掩盖失败。
5. **配置化适配**：角色、指标、反欺诈、评分卡、额度和舆情口径位于赛题场景配置；现场新数据优先导入与换配置，不改核心引擎。
6. **合规与脱敏**：输入输出双端检查，敏感内容外送前掩码；运行时模型固定为 `deepseek-v4.1-flash`，不接入低代码编排平台。

## 当前运行预算边界

- 默认**不限制**单次 run 的总工具轮数和总墙钟时间，不承诺固定秒数完成。
- 全局累计 token 保护上限为 1,048,576；赛题 04 场景覆盖为 200,000。
- 普通模型调用默认超时 30 秒；报告角色单次调用超时 60 秒；各角色配置一次重试。
- 上述是内部保护参数，不是官方评分时限；最终口径以 `app/config.py` 与 `scenarios/dd04/agents.yaml` 为准。

## 主动披露的边界

- 当前 PDF **输入**不支持，需先转换为结构一致的 CSV/XLSX 并人工核表；已发布回答可从前端导出 PDF/Word。
- 事实校验重点覆盖数字、评级等结构化事实；趋势、因果及部分语义判断仍需人工复核。
- 高风险样本的一致性仍不稳定；公开归档有两笔失败，不能宣称公开集满分。
- 官方非公开集尚未在仓库中产生；现有 5 笔文件是团队衍生演练。
- A6 已完成本机空目录离线安装预演，但异机干净 Windows、真断网双击 `start.bat` 和云服务白名单仍待验收。
- 自动化测试数量必须在最终 SHA 上重新执行后记录，不使用脱离版本的固定数字。
