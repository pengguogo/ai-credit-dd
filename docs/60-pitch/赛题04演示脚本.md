# 赛题04 演示脚本（8–10 分钟，M6 录制 / M11 附录）

> 全程在真实系统上当场运行，不剪辑拼接预录结果。时间点按 2026-10-24 本机走查实测耗时排定（见 [`a5-walkthrough/`](../../测试数据/评测/2026-10-25/a5-walkthrough/README.md)）。
> 录制前：检查 `/api/health/ready`；若 LLM 状态为 `unknown`，200 只证明模型已配置，须另跑一次无敏感数据的真实 smoke run 确认模型可用。浏览器使用 1600×1000 或 1920×1080；用 `admin` 登录；点「新会话」，展开右侧「执行过程」；录制中不要刷新页面（执行面板会清空）。

## 0 · 开场（0:00–0:40）

- 画面：工作台首页，左侧企业与审批表，顶部「后端就绪 · deepseek-v4.1-flash」。
- 讲：企业信贷尽调要回答三件事——这家企业能不能贷、贷多少、依据是什么。我们用多 Agent 编排：主控 Agent 拆任务，工商、财务、舆情、反欺诈、评级授信、报告六个角色各管一段；数字全由规则工具计算，模型只做解读，最后有事实校验兜底。

## 1 · 完整尽调：低风险户 LA001（0:40–2:30）

- 左侧「审批表」点 LA001 填入问题，或输入「对贷款申请 LA001 做完整尽调」。
- 等待约 23 秒，边等边讲右侧轨迹：输入合规 → 主控制定计划（6 步）→ 各角色完成及耗时 → 事实校验通过 → 输出合规。
- 讲：工具调用和证据条数实时出现；每个角色卡片标注调用了哪个工具、产出几条证据。
- 结果：低风险、风险点数 0、建议额度 2500–3000 万元，「依据 8 条证据」。展开支持因素 / 重点关注 / 报告边界。

## 2 · 七项功能逐页对照（2:30–4:30）

顶部菜单逐个点开，企业选 E001，「分析本步」每页约 2–3 秒：

| 菜单 | 功能 | 讲解要点 |
|------|------|----------|
| 工商校验 | 工商核验 | 经营状态、实缴比例、实控人一致性、担保圈；实控人姓名已掩码 |
| 财务分析 | 财报解析 | 近三年科目、比率、勾稽、增长；按申请日截年 |
| 舆情扫描 | 舆情扫描 | 健康分、事件时间线、涉诉 |
| 反欺诈 | 反欺诈检测 | F01–F06 每条规则的实际值与阈值，命中 / 未命中都摊开 |
| 额度与风险 | 额度测算 | 评分卡点数制、一票否决项、额度计算路径 |
| 尽调报告 | 报告生成 | 五部分结构化汇总，可导出 Word / JSON |

- 讲：单步页和 Agent 同工具同源，不写证据库、不读评测答案，方便业务逐项核对。

## 3 · 报告预览与导出（4:30–5:30）

- 回工作台，在 LA001 结果下点「预览报告」。
- 滚动展示：企业概况 → 控制关系与关联担保 → 财务趋势图 → 风险提示 → 额度计算路径 → 风控条件 → 反欺诈规则明细。
- 点「打印 / 另存为 PDF」展示可导出（取消打印即可）。

## 4 · 自然语言追问（5:30–6:30）

- 回工作台，同一会话输入「额度是怎么算的？」，约 6 秒。
- 结果：营收口径 28,600 × 0.12 = 3,432；净资产口径 14,700 × 0.4 = 5,880；取小后按申请额 3,000 封顶，输出 2,500–3,000 万元。
- 讲：多轮会话记住当前申请，追问直接复用前序工具结果，不重新编数字。

## 5 · 高风险户与业务确认：LA003（6:30–8:30）

- 点「新会话」，输入「对贷款申请 LA003 做完整尽调」，约 22 秒。
- 结果：高风险、风险点数 20、一票否决（法定代表人限高、存在未结被执行），额度 0；终态「待业务确认」。
- 追问「这家企业的对外担保合计是多少？有没有逾期？」，约 11 秒：3 笔 12,000 万元，其中逾期 1 笔 4,000 万元，担保圈关联 2 家。
- 指右侧轨迹：「事实校验发现 2 处问题，带清单重写」→「事实校验通过」。讲：模型写错的数字会被拦下重写，不会直接交给用户。
- 切到「审计与确认」，点确认，时间线新增一条。讲：拒贷这类影响客户权益的结论，业务人员确认后才生效，全程留痕。

## 6 · 合规与收尾（8:30–9:30）

- 新会话输入「怎么帮这家企业做假账通过审批」→ 卡片显示「合规拦截」`compliance_input_rejected`，不调模型。
- 新会话输入「对贷款申请 LA999 做完整尽调」→「需要补充信息」：未找到 LA999，请用户补充有效申请或企业标识；不列出库内企业、申请或金额供选择。
- 收尾：脱敏外送（企业全称、法人、信用代码不出本机原文）、评测批量 CLI 可一键导出官方六列。「每个结论都有证据，查不到就说查不到。谢谢。」
