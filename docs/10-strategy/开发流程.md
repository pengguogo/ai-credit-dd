核心答题链路：

```text
POST /api/agent/runs
  → 输入合规与对象定位
  → LangGraph 主控调用 run_dd_agents
  → 五角色确定性计算按依赖顺序完成
  → business / finance / opinion / fraud / rating 并行解读
  → report 汇总 → 发布前事实校验
  → 证据、轨迹、审计落库
  → 输出合规
  → succeeded / needs_confirmation / needs_clarification /
    insufficient_evidence / blocked / failed
```
