### 2026-10-22 · 引擎补强：状态机、超时、上下文管理（待办 1-1 / 1-4 / 1-2）
- 做了什么：
  1. 状态机：引擎按本次 run 的真实工具结果判定终态。新增内置工具 `request_clarification`（→ `needs_clarification`）；调用过工具却无证据、或答案含结论而无证据 → `insufficient_evidence`；工具结果命中场景确认规则（信贷：rejected / manual_review）→ `needs_confirmation`。说明文本走 `errorMessage`，经输出合规后写入会话历史。

### 2026-10-22 · 多模态输入（模型原生视觉）
- 做了什么：`POST /api/agent/runs` 支持可选 `attachments`（≤4 张、单张 ≤32MB），带图时 engine 把 user content 拼成 OpenAI 视觉协议的 content 块数组（text + image_url）直送 `deepseek-v4.1-flash`；前端聊天输入区支持选图、预览、删除、随消息发送；超限返回 422 `invalid_attachment`。
