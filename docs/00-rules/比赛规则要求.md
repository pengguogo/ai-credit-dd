## 01 完赛要求

> 三条硬性要求，决定作品能否参赛与完赛。

### ① 环境不限 · 模型使用规范

- 开发语言、运行环境不限；AI Coding 所用模型不限。
- **运行时模型严格限定为：`deepseek-v4.1-flash`。**
- 须交付**可本地一键启动**的完整全栈 Agent 系统（前端 + 后端 + 存储 + 模型调用）。

### ② 必须代码实现 Agent

- Agent 行为、工具编排、业务逻辑等，须由参赛团队**自行编写代码**实现。
- **严禁**使用「扣子（Coze）」等可视化无代码 / 低代码平台拼装 Agent。
- 违规者取消参赛资格。

### ③ 可用公开 Skill / MCP 完善架构

- 允许接入公开的 Skill、MCP 服务等组件，用于完善 Agent 架构与工具链（如增强记忆、检索、调用能力等）。
- 接入方式须在 **README** 中说明。

## 通用红线

- 答案证据须可追溯至数据或查询结果。
- 结论经业务人员确认后，须留有轨迹 / 日志。
- **禁止**在 Prompt 或工具中伪造（Mock）答案。
- **禁止**使用测试集或评委答案密钥填充作答。

## 03 评分规则

> 客观（AI 打分）+ 主观（评委打分），综合评定。

### 客观 · AI 打分

*测试集 + Agent 工程能力 + 合规，自动评测*

| 维度 | 内容 |
|------|------|
| **评测集** | 公开测试题（含结果）；非公开测试题（不含结果） |
| **Agent 工程架构完善度** | 上下文管理、Agent 编排、可观测性等 |
| **合规性** | 敏感词、政治性等（**强制项**） |

### 主观 · 评委打分

*现场演示与作品整体质量*

- 业务价值
- 演示完整度
- 技术创新
- 交互体验
