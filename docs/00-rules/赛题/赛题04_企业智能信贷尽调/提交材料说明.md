## 二、逐项说明

### 2.1 可运行系统包（Demo 或在线访问链接）

- **内容要求**
  - 支持输入企业信息后**自动完成尽调全链路**：财报解析 → 工商核验 → 舆情扫描 → 反欺诈检测 → 额度测算 → 尽调报告生成
  - 支持**自然语言问询**：识别客户经理尽调问题意图并给出结论与依据
  - 七项必选功能须全部可达：财报解析、工商核验、舆情扫描、反欺诈检测、额度测算、尽调报告生成、自然语言问询
  - **不得**直接基于多个 CSV 做简单 LLM 应用输出，须为 Agent 系统，支持数据导入、解析、分析、解释、决策、可视化完整流程
- **格式要求**
  - 源码 UTF-8 无 BOM，LF 换行；提供容器化或等价一键脚本
  - 若以在线链接形式提交：须在 `manifest.yaml` 与邮件正文写明 URL、可用时间段、账号（如有）
- **命名规范**：`星火队_赛题04_可运行系统包.zip`

### 2.2 源代码与部署说明

- **内容要求**
  1. 环境依赖与版本
  2. 数据导入方式（10 张 CSV + `schema_relationships.csv` 的关系装载）
  3. **可直接复制执行的启动命令**
  4. 访问地址与默认端口
  5. 多 Agent 角色划分与编排配置路径
  6. 反欺诈规则、财务指标口径、额度测算模型的**配置文件路径**（须可配置，非硬编码）
  7. 批量运行公开测评集的脚本路径与用法
- **格式要求**：`README.md`，UTF-8
- **命名规范**：`README.md`（置于提交包根目录）

### 2.3 技术方案说明

- **内容要求**（建议章节）
  1. 多 Agent 架构图：角色划分、协作协议、编排方式
  2. 数据导入与建模：10 张表的主外键装载、口径统一
  3. 财报解析：近三年营收、利润、资产、负债、现金流等核心科目解析，偿债 / 盈利 / 营运指标计算
  4. 工商核验：基础信息一致性、经营异常、关联企业、对外担保
  5. 舆情扫描：涉诉、行政处罚、负面舆情 → 风险标签与评分
  6. 反欺诈检测：营收与现金流背离、存货异常、关联交易占比过高等线索及关联欺诈风险
  7. 额度测算模型：财务指标 + 风险评级 + 贷款用途 → 建议授信额度、期限与利率，**须说明测算依据**
  8. 尽调报告生成：企业概况、财务分析、风险提示、额度建议、风控条件
  9. 自然语言问询：意图识别与结论溯源
  10. 记忆系统、会议与资产管理、工具调用、Skill 管理四项工程能力的实现
  11. 鲁棒性与可解释性设计、合规性设计
- **格式要求**：A4 PDF，≥10.5pt，≤30MB；**须同时提供同名 `.md`**
- **命名规范**：`星火队_赛题04_技术方案.pdf` / `.md`

4. **引用开源组件须声明 License**。所有使用的开源库须逐条声明名称、版本、License、用途与来源链接。
5. **公开测评集仅用于自测**。不得写入提示词、不得用于预填结果；非公开测评集赛前不下发、现场提供。
6. **法律法规条款不得编造**。政策、法规、条款、标准编号与条文内容不得由模型幻觉生成，更不得作为结论依据。
