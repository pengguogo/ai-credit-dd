# 非公开测试集 · 企业数据包（现场提供 · 仅输入）

> 本数据包仅包含企业级**输入数据**，不含任何风险评级、建议额度、尽调结论、评分要点等结果字段。
> 与 `01_非公开测试集_输入_现场提供.csv/.xlsx`（申请编号→企业编号清单）配套使用。

## 一、内容

| 文件 | 行数 | 说明 |
| --- | --- | --- |
| `enterprise_basic.csv` | 20 | 企业基础信息 |
| `enterprise_shareholder.csv` | 55 | 股东结构 |
| `enterprise_finance.csv` | 60 | 2021–2023 三年财务数据（每家 3 行） |
| `enterprise_public_opinion.csv` | 65 | 舆情事件明细 |
| `enterprise_lawsuit.csv` | 63 | 涉诉案件明细 |
| `enterprise_related.csv` | 88 | 关联企业明细 |
| `enterprise_guarantee.csv` | 36 | 对外担保明细（仅列有担保记录的企业，未列出的企业视为无对外担保，以 `enterprise_risk` 汇总为准） |
| `enterprise_risk.csv` | 20 | 风险汇总（每家 1 行） |
| `loan_application.csv` | 20 | 贷款申请要素（`LA011`–`LA030`，与 01_ 清单逐行对齐） |
| `07_补充_非公开企业数据_现场提供.xlsx` | — | 上述 9 张表的同名 sheet 副本，便于现场查看 |

- 企业范围：`E011`–`E030`，共 20 家，与公开数据包 `E001`–`E010` 无重叠（企业名称、信用代码、法人均不重复）。
- 申请书范围：`LA011`–`LA030`，共 20 笔，与 `01_` 清单的 `application_id` 一一对应。

## 二、口径约定（与公开数据包完全一致）

| 项目 | 口径 |
| --- | --- |
| 金额 | 全部为**万元**（人民币），如 `12500` = 1.25 亿元 |
| 日期 | `YYYY-MM-DD` |
| 比例 | `shareholding_ratio` / `contribution_ratio` 为百分数（如 `51.0` 表示 51%） |
| 财务年度 | `year` ∈ {2021, 2022, 2023}，每家 3 行 |
| 枚举 | `business_status`：在业；`guarantee_type`：一般保证/连带责任保证/抵押担保；`loan_application.guarantee_type`：抵押担保/信用担保/保证担保；`is_overdue`、`legal_person_dishonest`、`legal_person_consumption_limit`：是/否 |
| 编码 | CSV 为 UTF-8（含 BOM），行尾 CRLF；列名、列序、字段类型均与参赛者 `data/` 下同名表**完全一致** |
| 关联 | `enterprise_basic.related_enterprise_count` = `enterprise_related` 中该企业明细行数；`enterprise_risk.external_guarantee_amount` = `enterprise_guarantee` 该企业担保金额合计 |

## 三、现场使用方式

1. 将本目录下 9 个 CSV **原样拷贝**到系统数据目录（或直接把系统的数据根路径指向本目录），文件名与公开包同名，无需改代码即可加载。
2. 按 `01_` 清单中的 `application_id` 逐笔出具风险评级、建议额度、尽调结论与依据。
3. 判分以评委留存的标准结果按 `application_id` 比对，**本包不含任何结果**。

> 若系统按 `data/` 目录名硬编码，建议改为可配置的数据根路径；本包即用于验证"改配置即可适配新样本"。
