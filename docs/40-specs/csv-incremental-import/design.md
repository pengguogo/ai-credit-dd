# CSV增量导入 设计

状态：已确认    对应需求：已实现

## 方案概述
JSON传输文件名和UTF-8 CSV文本，不加multipart依赖。路由调用导入服务，服务先校验和比对全部记录，再统一插入与提交。仅相同行跳过；候选键冲突返回422。单进程锁保护导入API中的明细去重，现有唯一约束处理数据库冲突。

## 涉及模块与负责人
数据层：导入服务、models/migrations；Agent公共接口：路由与schemas；前端：api.importCsvFiles。用户本轮授权必要接口改动，不改Agent编排或模型入口。

[CSV导入契约](../../../contracts/agent-api.md)：POST /api/agent/data/imports；沿用X-Actor-Id。

## 红线影响
