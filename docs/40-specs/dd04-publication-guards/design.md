# 尽调发布门禁 P0 最小修改设计

状态：草稿    对应需求：已确认（[需求](requirements.md)）

## 方案概述
1. **J01：无证据默认拒绝普通成文。** 修改 `engine._finish_with_answer`：企业尽调场景凡本次 `outcome.evidence_ids` 为空，统一走现有 `insufficient_evidence / evidence_missing`，不再以三个结论关键词决定是否要求证据。在设置 `answer` 前判定；返回前清空原答案，写固定说明“本次未取得业务数据证据，无法形成结论，请提供或核对企业、申请信息后重试”。已有“查无对象”检查继续保留。普通模型回复、终止工具的 `finalAnswer` 已共用此函数，两条路径都生效。证据 ID 仅由本次 `persist_evidence` 写入取得；模型声称查过、正文引用旧 ID、历史消息均不算本次取证。追问重新调用现有工具，不增加跨轮证据复用机制。
2. **澄清与职责说明。** 保留 `request_clarification → needs_clarification`；无本次证据时将用户可见澄清文本收敛为固定补充信息提示，避免把业务断言夹进澄清说明。本轮不靠语义分类器或扩充业务词表放行闲聊：无证据的普通问候、职责说明也会进入证据不足；这是最小方案的明确兼容性代价，不能宣称所有闲聊行为保持不变。若要保留闲聊成功，另行确认受控固定回复方案。
3. **J02：在现有输出合规中禁止具体法规引用。** `checker.py` 增加 `legal_reference` 类别、固定用户提示及组合规则；检测法规名称（含书名号和“根据/依据”等引述形式）、中文/阿拉伯数字条号、常见监管文号（含〔〕/[]/全角括号与“号”）。覆盖“《虚构企业信贷尽调法》第999条”“依据某某法”“第九十九条”“银发〔2026〕999号”；真实法名同样拒发，不做真伪白名单。规范空白/全角形式后检查，泛称“依法合规”和内部 B/F 规则编号放行；书名号本身不作为命中依据。复用 `_apply_outcome`，返回 `blocked / compliance_output_blocked`、清空答案、保留 `compliance_blocked` 审计；有证据、高风险待确认与澄清也不豁免。不静默删掉法规后发布，不自动重试。
4. **验证落点。** `test_agent_runs.py`：对无工具、工具无证据、伪造旧证据 ID、历史追问无新证据、终止工具无证据分别注入反例；检查终态、answer、errorMessage、会话历史，确保无原断言泄漏；正常取证追问、完整报告、高风险确认与澄清回归。`test_compliance.py`：法名/条号/文号、真名假条文及格式变体，另测普通分析、内部规则、普通书名；HTTP 集成用“已有证据+虚构法规”防止 J01 提前拦截掩盖 J02，覆盖 sync/async 与拒发审计。重跑原 probe 仅比较 J01/J02，J03 仍列未解决。之后后端全测、红线扫描、正常公开申请/问询真实抽验；源码实施后按项目约定启动并验证开发服务。仅设计阶段不宣称修复通过。

## 涉及模块与负责人
Agent核心：`engine.py`（公共层）；合规与可观测：`checker.py`（公共层）；对应回归测试与契约文档。现有 `run_service._apply_outcome` 复用，原则上不改；不改前端、计算、角色编排和提示词。实施前确认本设计即完成上述公共层修改范围沟通。

## 接口 / 契约变更（链接 /contracts）
字段、状态和错误码无新增；[Agent API](../../../contracts/agent-api.md) 的终态语义需要同步：取消企业尽调无证据普通回复可成功的例外、明确证据不足固定说明及法规拒发。实施时先改该契约再改代码；本轮保留现行契约，不把设计草稿写成已生效能力。

## 数据变更（表、字段、迁移方式）
无。复用 evidence、run、message 和 audit；历史记录不回写，不增加迁移。

## 红线影响（对照 30-standards/redlines.md 逐条说明）
R1：无影响，不增加模型入口/调用。R2：无影响，代码门禁。R3：补齐本次无证据拒发；有证据不等于逐句正确，J04另修。R4：固定错误提示不包含业务结论。R5：无影响，不读标签。R6：无影响，保留高风险待确认，不修J03身份。R7：增加法规引用拒发与原有审计。R8：无影响，不加依赖。R9：无影响，不处理或复制凭据。

## 取舍（选择了什么、放弃了什么、何时重访）
选择保守门禁，放弃关键词判断全部业务断言、额外 LLM 审查与法规知识库；代价是无证据自由闲聊被收紧、追问重新取证、真实法规也被拒发。规则检测不证明任意隐晦改写都可识别，按上述对抗用例验收；出现漏检则补规则，不能声称完整法律语义理解。需要跨轮免重查或合法规引用时，再设计证据版本/对象/有效期或可信法规源。本方案只关闭 J01 的无证据发布路径与 J02 的显式引用缺口，不代表全部评测放行。
