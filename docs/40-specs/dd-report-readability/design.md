# 设计
## 方案概述
报告首页列出三个独立状态；审批取本次 loan_application 原始查询快照。主控提示区分语义，问实际审批必须读取贷款状态。报告/财务提示限制技术措辞；预览显示层兼容已有正文。按报告主体与申请过滤当前 run 证据，每类计算取最后一条匹配项；关键结论链接至末章内的证据区，不改变七章结构。父页面接管沙箱内锚点并展开对应原生详情。
## 涉及模块与负责人
前端：报告预览、纯函数与测试；场景：主控/财务/报告提示与报告技能。按用户指定三项范围协同修改。
## 接口/契约变更
无。复用 Evidence、RunDetail。
## 数据变更
无。审批为生成时查询快照，不是当前实时状态；缺失不推断。
## 红线影响 R1–R9
模型入口、锁定模型、代码编排、工具注册不变；无答案输入、硬编码业务结论或凭据；只链接真实 evidence，保留失败与缺证提示；沿用脱敏与 HTML 转义；无审批写入或审计修改；无新增依赖。
## 取舍
采用报告内依据区，使打印保留证据；保留原始技术快照以供核对，仅业务正文转换技术措辞。跨轮普通问答仍用主控与工具回答，不显示报告进度。

## 后续调整
HTML 报告采用精简展示：删除首页三状态卡及末章证据附录，清理相关目录、锚点入口、专用样式和打印展开操作；对话状态、证据存储和业务措辞转换保留。静态渲染验证七章仍在且不存在失效锚点。
