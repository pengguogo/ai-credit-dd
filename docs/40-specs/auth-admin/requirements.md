## 背景

演示工作台原先用自由填写的 `X-Actor-Id`。需要正式登录入口与账号/角色管理，便于演示权限与多人身份。

## 用户故事

1. 作为演示用户，我可以在登录页用账号密码进入工作台。
2. 作为管理员，我可以在「系统管理」查看/新增角色与用户，并停用账号。
3. 作为评测脚本，我仍可用 `X-Actor-Id` 调用 Agent API（不强制登录，不套演示 RBAC）。

## 验收标准

| 编号 | WHEN | THEN |
|------|------|------|
| A1 | 使用正确账号密码登录 | 获得 Bearer token，进入工作台，顶栏显示显示名与角色 |
| A2 | 密码错误 | 401，不签发 token |
| A3 | 管理员打开系统管理 | 可列出角色/用户，新建用户与角色，停用账号 |
| A4 | 非管理员访问 `/admin` 或管理 API | 前端回工作台；API 403 |
| A5 | 未登录打开业务页 | 跳转登录页 |
| A6 | 既有 pytest 仍带 `X-Actor-Id` | 行为不变（评测旁路不套演示 RBAC） |
| A7 | `viewer` 登录 | 可见工作台与尽调 1–5 步；无数据列表菜单（缺 `applications`）、无确认/系统管理；工作台内可读企业基础信息 |
| A8 | `account_manager` 登录 | 用户名与角色码均为 `account_manager`，顶栏角色为“客户经理”；可办理审批表通过/驳回与结论确认；无系统管理 |

## 角色说明（演示种子）

| 账号 | 角色 | 能力 |
|------|------|------|
| `admin` | 系统管理员 | **全部权限**：系统管理 + 工作台 + 审批表通过/驳回 + 结论确认 + 数据写 + 尽调 1–5 步 |
| `account_manager` | 客户经理（`account_manager`） | 发起尽调 + 业务办理（审批表通过/驳回、结论确认）+ 数据写 + 尽调 1–5 步；无系统管理 |
| `viewer` | 只读访客 | 顶栏：工作台 + 尽调 1–5 步；工作台内可见企业基础信息；无数据列表/审批表/确认/系统管理/写库 |

权限码：`admin` / `workbench` / `dd_steps` / `catalog` / `applications` / `confirm` / `catalog_write`。

说明：`viewer` 种子可带 `catalog` 以便工作台读企业基础信息，但前端「数据列表」菜单要求 `catalog && applications`，故访客看不到数据列表。

## 排除项

- 不做 OAuth / SSO / 短信验证码。
- 不做细粒度菜单级 RBAC 引擎（权限码列表即可）。
- 不把真实生产密码写入仓库；演示口令仅种子数据。
