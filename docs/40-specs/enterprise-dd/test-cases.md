# 企业信贷尽调 设计用例

状态：已确认

| 编号 | 追溯 | 类型 | 前置 | 操作 | 期望 | 验证 |
|------|------|------|------|------|------|------|
| TC-1 | 需求 6 | 正常 | 用户问题含数据库中可识别的企业名或自然人姓名 | 创建 run 并检查保存的提问、用户消息、会话标题、模型消息及 `llm_calls` 预览 | 保存文本保留企业名称、将库内已知自然人替换为代号，其他 PII 掩码；模型请求和审计预览不含名称原文 | 接口 |
| TC-2 | 需求 6 | 正常 | 企业尽调工具返回企业名、法人、实控人、股东或关联企业名称 | 执行工具循环并检查下一轮模型请求 | 工具结果中的名称均为本次 run 代号；企业编号和申请编号保留 | 接口 |
| TC-3 | 需求 6 | 正常 | 主控或报告角色生成含代号的最终回复或澄清问题 | 完成 run 并检查输出合规、保存消息及 API 回复 | 输出合规检查前仅还原企业名称；自然人保持代号；号码类值保持掩码 | 接口 |
| TC-4 | 需求 6 | 正常 | 模型返回的工具参数包含此前收到的实体代号 | 调用对应本地工具 | 工具收到原实体值并正常查得对应证据；模型请求和审计预览不含原名 | 接口 |
| TC-5 | 需求 6 | 红线 | 当前问题及模型响应含信用代码、法人证件号 | 检查模型请求和最终发布内容 | 请求中的号码按现有规则掩码；输出不还原号码原文；不影响企业编号和申请编号 | 单测 |
| TC-6 | 需求 6 | 异常 | 模型响应包含未登记的代号，包括已知代号 E001 的未知延长形式 E0010 | 完成 run | 未登记代号不映射为任何其他实体；不得因前缀匹配或二次替换泄漏映射中的其他名称 | 单测 |
| TC-7 | 需求 1 | 正常 | 存在申请与完整事实数据；假模型可规划完整尽调 | 发起完整尽调 run | 出现 `run_dd_agents`；证据含 `source_type=calculation`；结论中的风险档位与额度来自 rating/credit 计算证据 | 单测 |
| TC-8 | 需求 1 | 异常 | 申请编号不存在 | 发起尽调 | `errorCode=not_found` 或澄清终态；响应无可用 riskLevel 与正数额度 | 接口 |
| TC-9 | 需求 2 | 正常 | 完整尽调成功且有正文 | 打开对话区导出 PDF / Word | 文件可下载；正文与回复一致；信用代码与证件号已掩码 | 手工 |
| TC-10 | 需求 3 | 红线 | 库内 `enterprise_risk` 含 `risk_level_summary` | 跑尽调并检查工具结果、证据、目录与 sql_query | 运行时输出不含外部汇总评级键；显式 SELECT 该列被拒绝 | 单测 |
| TC-11 | 需求 3 | 正常 | 命中反欺诈规则 | 执行 fraud / rating | 命中项含规则编号、命中值、阈值；`riskLevel` 为评分卡档位名 | 单测 |
| TC-12 | 需求 4 | 边界 | 企业名称命中多家 | 调用 `find_enterprise` | `matchStatus=ambiguous`；结果无 riskLevel 与建议额度 | 单测 |
| TC-13 | 需求 5 | 正常 | 已有含 succeeded 与 needs_confirmation 的 eval.run 结果 | `python -m eval.dd04 export` | 六列 utf-8-sig；另有 status CSV；行与申请一一对应；不打开答案文件 | 单测 |
| TC-14 | 需求 7 | 异常 | 申请时点前无可用完整年度财报 | 执行 rating 角色计算 | 出现 `creditError`；无正数建议额度；触发复核或确认信号 | 单测 |
| TC-15 | 需求 3 | 正常 | 点数制评分卡与 incremental-v2 额度配置 | 离线或合成用例调用 `rate_risk` / `calc_credit_limit` | 档位与额度按 yaml 计算；反欺诈多命中不强制一票否决为高风险额度 0（除非评分卡否决项） | 单测 |
| TC-16 | 需求 6、7 | 红线 | 合成姓名与数值反例 | 创建 run、检查输出及事实校验 | 已知自然人不以明文出现在持久化提问或答案；科目、符号、明确年度错误被拒绝；正确换算通过 | 单测 |
