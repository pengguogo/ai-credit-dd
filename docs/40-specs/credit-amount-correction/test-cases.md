# 信贷金额专项修复 设计用例

状态：已确认

| 编号 | 追溯 | 类型 | 前置 | 操作 | 期望 | 验证 |
|------|------|------|------|------|------|------|
| TC-1 | 需求 1、3 | 正常 | 合成收入/权益上限够，存量/担保高于申请 | 算额度 | 不直接扣敞口，仍按申请封顶；敞口/政策与条件可查 | 单测 |
| TC-2 | 需求 3 | 边界 | 合成财务容量高于申请；中风险 | 算额度 | 先乘评级系数，再按申请额封顶，区间不超过调整后能力 | 单测 |
| TC-3 | 需求 3、4 | 边界 | 合成营收或净资产非正 | 算额度 | 财务零上限保留，额度为零 | 单测 |
| TC-4 | 需求 3、4 | 边界 | 合成现金流非正；其他财务能力充足无否决 | 算额度 | 复用中风险系数折减，不自动归零；条件解释非精确偿债测算 | 单测 |
| TC-5 | 需求 4 | 边界 | 高风险，或低风险但有否决 | 算额度 | 均输出零，非正现金流调整不能解除否决 | 单测 |
| TC-6 | 需求 2、3 | 异常 | 无财报、必需科目缺失/非有限、非法申请/政策/单位 | 算额度 | ToolError，无正数假建议 | 单测 |
| TC-7 | 需求 3 | 边界 | 十进制边界、容量不足一步、不同步长/带宽 | 算额度 | 精确向下取整，区间不越容量或申请额，不上抬不足步长值 | 单测 |
| TC-8 | 需求 2 | 边界 | 合成财报含未来及申请年度，乱序 | 按申请日期分析并算额度 | 只用此前最近完整年度，未来数据不影响结果 | 单测 |
| TC-9 | 需求 3、4 | 红线 | 同事实改编号/乱序，增申请额/敞口/风险 | 算额度 | 无编号特化；金额不突破容量；敞口增加不会增额，风险提高不增额 | 单测 |
| TC-10 | 需求 2、5 | 正常 | 假模型+临时库+合成未来财报 | 执行财报/评级/反欺诈/额度/报告工具 | 同一年度，金额和证据一致；不暴露白名单外字段 | 接口 |
| TC-11 | 需求 6 | 正常 | 合成已算结果含失败和非数值参考 | 离线评分 | 精确/重叠/包含分别算，失败在总分母，无法数值化单列 | 单测 |
| TC-12 | 需求 5、6 | 红线 | 公开输入剥离标签，政策冻结 | runner 复测并对比事实、参考和最终文本 | 标签不进运行时，不修数据/调参；事实正确不等于 Agent 成功，最终文本不一致单列 | 手工 |
| TC-13 | 需求 5、6 | 边界 | 合成千位逗号、不同区间连接符、亿元文本 | 离线抽取明确建议金额 | 正确统一单位/格式，不按编号特化，不把格式遗漏改成业务金额，不改写原答复 | 单测 |
