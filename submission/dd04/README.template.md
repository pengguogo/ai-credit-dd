## 3. 启动命令

现有底座开发启动命令如下；最终包仍须干净环境验证，不能视为赛题 04 已验收：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1            # 开发（联网安装依赖）
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Offline   # 提交包（只从 vendor/wheels 离线安装）
```

运行环境只支持 Windows。评委机双击 `start.bat` 即可：不需要预装 Python / Node.js，脚本只用包内的 Python 3.14.9 与 `vendor/wheels` 离线安装。依赖逐项说明见根目录 README"依赖与离线内置说明"。远程模型不可用时如实失败，不提供预填答案。
