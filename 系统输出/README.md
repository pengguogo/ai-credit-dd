## Windows PowerShell 格式复验

从仓库根目录执行：

```powershell
Set-Location ".\ocft-backend"
$Py = ".\.venv\Scripts\python.exe"

& $Py -m eval.dd04 validate `
  --applications "..\docs\00-rules\赛题\赛题04_企业智能信贷尽调\data\loan_application.csv" `
  --results "..\系统输出\公开测评集结果.csv"
```
